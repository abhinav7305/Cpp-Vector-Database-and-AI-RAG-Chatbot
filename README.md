# Cpp-Vector-Database-and-AI-RAG-Chatbot
C++ Vector Database and AI-RAG Chatbot implementing HNSW, KD-Tree, and Brute Force search with semantic embeddings, Ollama, and Llama 3.2. Supports document ingestion, vector search, RAG-based question answering, REST APIs, algorithm benchmarking, PCA visualization, and real-time semantic retrieval through a web interface.
